# Sariya Anjum — Portfolio

A responsive React + Vite portfolio with a dark/purple visual theme, mobile navigation, theme toggle, scroll reveal, project links, and downloadable resume.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy on Vercel

1. Push this folder to a new GitHub repository.
2. Sign in at https://vercel.com/ and choose **Add New → Project**.
3. Import the portfolio repository.
4. Keep the detected Vite settings: build command `npm run build`, output directory `dist`.
5. Click **Deploy**. Copy the live URL Vercel gives you.

The site uses your resume details and the two projects listed there. Update the project URLs if you rename those GitHub repositories.
